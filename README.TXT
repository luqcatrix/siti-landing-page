==================================================
        PETUNJUK INSTALASI SITI DESKTOP PET
==================================================

Siti Desktop Pet & Ekstensi Browser Anti-Doomscrolling
Sistem Operasi: Windows 10 / 11
Browser Supported: Google Chrome, Microsoft Edge, Brave, dll.

--------------------------------------------------
1. CARA INSTAL APLIKASI DESKTOP (.exe)
--------------------------------------------------
1. Unduh file "Siti_DesktopPet_Setup_v1.0.exe".
2. Klik dua kali (double-click) pada file installer tersebut.
3. Ikuti petunjuk instalasi di layar sampai selesai.
4. Buka aplikasi Siti dari Start Menu atau Shortcut Desktop.

* Cara Verifikasi: Siti akan muncul dan melayang di desktop kamu.


--------------------------------------------------
2. CARA INSTAL EKSTENSI BROWSER (.zip)
--------------------------------------------------
1. Unduh file "siti-ekstensi.zip".
2. Klik kanan file .zip -> pilih "Extract All..." (Ekstrak Semua).
3. Buka browser (Chrome / Edge / Brave).
4. Masuk ke halaman ekstensi dengan mengetikkan:
   chrome://extensions  (di Chrome/Brave) atau
   edge://extensions    (di Microsoft Edge)
5. Aktifkan sakelar "Developer mode" (Mode pengembang) di pojok kanan atas.
6. Klik tombol "Load unpacked" (Muat yang tidak dikemas).
7. Pilih folder "siti-ekstensi" hasil ekstrak.

* Cara Verifikasi: Ekstensi "Mata-Mata Siti" terpasang dan muncul aktif di daftar ekstensi tanpa ada peringatan merah.


--------------------------------------------------
CATATAN PENTING:
- Pastikan Aplikasi Desktop dan Ekstensi Browser sama-sama berjalan agar fitur anti-doomscrolling dapat terhubung.
- Ekstensi mendeteksi pemutaran video di TikTok, YouTube Shorts, dan Instagram Reels. Siti akan merespons dan menutup tab tersebut.
